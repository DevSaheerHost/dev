Project overview

A practical build combining camera hardware and Linux services.

What I built

A CCTV recording workflow with a live monitoring interface, background recording service and dedicated USB storage. The system exposes camera and recorder status through a browser-based dashboard.

Build & implementation

The main pieces of the system.

01 / CAMERA

Device setup

Detected and configured the Lenovo USB UVC camera through Linux video devices and V4L2 tools.

02 / RECORDING

Video pipeline

Used FFmpeg to capture and encode camera footage, then checked output properties with ffprobe.

03 / RELIABILITY

Storage & automation

Mounted dedicated USB storage and configured a systemd service to run the recorder in the background.
